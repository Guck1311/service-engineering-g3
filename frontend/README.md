# Music Collection Manager - Frontend

Vue 3 single page application for the Music Collection Manager backend.

- How to run, test and build: [root README → Frontend](../README.md#frontend)
- How it is built and how Vue works (lecture-style documentation):
  [`docs/exercise-2-frontend.md`](../docs/exercise-2-frontend.md)

## Recommended setup

- VS Code with the [Vue (Official)](https://marketplace.visualstudio.com/items?itemName=Vue.volar)
  extension (type support for `.vue` files).
- [Vue.js devtools](https://devtools.vuejs.org/) browser extension: inspect components,
  Pinia stores and routes. In development it is also built in (`vite-plugin-vue-devtools`).
